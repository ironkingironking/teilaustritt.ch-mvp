Kirchenaustritt im Kanton Tessin

Im Tessin gibt es keine kantonale Kirchensteuer; nur ein Teil der Pfarreien erhebt eine Imposta di culto (Kultussteuer) von den im Steuerkatalog eingetragenen Katholiken. Den Austritt aus der kirchlichen Körperschaft erklärt man schriftlich beim Consiglio parrocchiale der Wohnsitzpfarrei. Wo die Pfarrei eine Imposta di culto erhebt, verlangt man beim selben Rat schriftlich auch die Befreiung davon; sie wirkt ab dem folgenden Kalenderjahr.

Das gilt im Kanton Tessin

  • Nur ein Teil der Pfarreien erhebt eine Kultussteuer (imposta di culto). Wer im Steuerkatalog der Pfarrei eingetragen wird, kann innert eines Monats schriftlich die Befreiung verlangen; später wirkt eine Erklärung auf das folgende Jahr.
